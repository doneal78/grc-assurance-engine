Simulated ServiceNow file

The JSON object sets import_kind to servicenow_vendor_intake and simulation to true, and includes a note that the file was not retrieved from ServiceNow. result is a list of tickets. number, category (vendor_risk), and attachments are required. Assessment answers and the trust-center URL use a u_ prefix, for example u_vendor_name and u_data_sensitivity. Evidence choices are attachment metadata: u_intake_field names the questionnaire evidence column and u_evidence_option is one of the six evidence keys. The CSV form flattens those evidence choices into u_ columns on the ticket row.

state, priority, assignment_group, opened_at, short_description, description, and sys_id are shown on the preview and are not scored. opened_at does not change the evaluation date. Two rows for the same vendor are a conflict, including two attachments that give different options for one field. The extra row is reported and is not dropped.

Full field list and limitations: docs/import-formats.md.
