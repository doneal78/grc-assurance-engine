# Changelog

This file records portfolio history that used to live in the build-plan status paragraph. It is not a release log, and it does not claim production effectiveness.

## Through 2026-10-30

**Project status:** Phases 1–7 initial demo slice implemented. An illustrative org policy profile and a human decision record were added after that slice. Required contract clauses are checked against evidence. The public intake questionnaire is versioned. Questionnaire 1.1.0 adds optional vendor-direction context for a reviewer. Those fields are not scored, and the residual formula is unchanged. Trust-center citations can be pasted, or a reviewer can request one HTTP GET that stores the page for human review. A fetch is not verified evidence. File import does not fetch. A per-vendor reviewer package can be exported. A file importer on `/try/import` reads questionnaire CSV and `.xlsx` files and a simulated ServiceNow JSON or CSV ticket file. It previews the rows, then runs them through the existing intake path. It does not call ServiceNow. Preview and confirm do not save. A person can then save one synthetic row with a disposition and rationale. A bot JSON contract and CLI run the same intake path. Assess alone does not save. `persist: true` with a human disposition does. The dashboard reports observed register counts, elapsed intake-to-disposition time, optional self-reported handling minutes, optional self-reported rework minutes, optional self-reported manual touches, and optional self-reported handoffs on a disposition, kept separate from the illustrative cost formula. Those four figures are not a stopwatch and are not cash savings. Observed metrics definition 9 also shows a monthly assessment rate when decision timestamps cover 30 days, authenticated effort when a signed-in reviewer stored minutes, and cash savings when that reviewer stored whole dollars. A public try does not collect the last two. Avoided-incident value is a modeled assumption on its own card. The shipped file leaves `incident_cost` and `avoided_incident_count` null, so that card says Not measured. None of those figures is copied into `calculate_cost()`. The control-mapping library is listed at `/mappings`. Mapping set 0.2.0 includes a small draft NIST SP 800-53 set and draft ISO/IEC 27001 and ISO/IEC 42001 review prompts. Those entries remain draft. Multi-tenant policy storage is not implemented. `/walkthrough` is a guided path over the existing pages, including a custom vendor and the optional trust-center choice on `/try/`, the conflicting-permissions scenario, and `/try/import`. A browser cookie remembers the last stop for 12 hours. The guide does not score or save on its own. Workflow events carry a SHA-256 hash chain. Rows that already existed are marked chained after the fact. The chain is tamper-evident. A person who can rewrite the database can rebuild it, so it is not immutable storage, a production audit log, or a certification. See section 24. A browser's opt-in saves go into a signed-cookie sandbox. That cookie is not a login. Seeded scenario pages stay shared and read-only. See section 25. A reviewer can write a finding on a saved assessment. The finding stays in that browser's sandbox, is labeled reviewer-authored, and does not change the residual tier. See section 26.
